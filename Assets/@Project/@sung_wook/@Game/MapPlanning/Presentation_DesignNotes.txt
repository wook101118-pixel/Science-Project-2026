Play 중에는 2~5, R 재시작, A/D 또는 방향키, 기존 마우스 레버를 사용한다.
Stage 03: B 기준, E 발사, T 복귀, Z/X/C 공 전하량, V/N 전극 전하량.
Stage 04: Z 양전하, X 음전하, C 중성. Stage 05: 레버 충전 후 E 발사.

공통 시각 규칙
충돌 발판의 상단은 밝고 선명한 금속 캡, 몸체는 중간 명도, 배경 구조는 낮은 대비로 구분한다.
리벳·이음선·끝단·표시등을 동일한 부품 언어로 사용한다. 노란 별과 민트 출구를 강조한다.
공의 기존 +/−/0 표시와 E/F 화살표는 유지한다. UI 색과 글꼴은 씬에 미리 저장한다.
기존 큰 영어 제목·긴 월드 TextMesh·이전 배경 그룹은 비활성 보관했다.
저장된 카메라의 orthographic size는 6.6이며 화면 위·아래에 공통 UI 여백을 두었다.

검증 증거
프로젝트와 같은 Unity 6000.3.19f1의 별도 검증 복사본에서 원본 씬 파일을 그대로 실행한다.
원본 씬 해시 일치, 기존 물리·컴포넌트 보존, 학습/차단/실제 경로/최소 전압/실행 화면을 검사한다.
완주 검사는 기존 PlayerMovement.SetMovex와 공개 학습/레버 명령을 사용하며,
도중 순간이동·별 수집/클리어 강제 호출을 하지 않고 실제 물리 이벤트를 관찰한다.
화면 캡처는 실제 Unity Play 렌더링이다. 비교 기준·음전하·55.5V 상황을 보여주기 위한
화면 확인용 준비 상태는 완주 검사와 별개이며, 학습 판정의 증거는 완주/목표 보고서이다.
최종 결과: 프로젝트 루트 Logs/ElectricPolish*Report.json과 ElectricPolishStage02~05.png.
학습 41개, 클리어 차단 35개, 실제 경로 4개, 약 50.5V 최소 충전 경로가 통과했다.
기존 컴포넌트 110개와 물리 Transform 및 조상 78개의 설정이 동일하다.
Missing Script 0개, 실행 중 오류 0개이며 2240×1260의 실제 16:9 캡처를 확인했다.
오류/검사 수치와 씬 SHA256은 해당 보고서가 기준이다.
청각적 음량 평가는 수행하지 않았으며, 저장된 저음량 AudioSource와 클립 로딩/상태 연결을 검사했다.
