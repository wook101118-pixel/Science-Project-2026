대상

이번 수정 방법
Unity Hub에서 Science-Project-2026 / Unity 6000.3.19f1을 열고,
Unity의 Load Scene 대화상자로 원본 sungwook 씬을 열었다.
Hierarchy 검색·선택·Ctrl+D 복제와 Inspector Transform/이름 입력으로 수정하고 Ctrl+S로 저장했다.
씬 데이터를 작성하는 임시 스크립트, Unity API 배치 도구, 디자인 생성기, 새 C# 파일을 사용하지 않았다.
기존 스프라이트 Square(guid 311925a002f4447b3a28927169b83ea6)만 복제해 장식 15개를 배치했다.
각 장식에는 Transform과 SpriteRenderer만 있고 Collider나 기능 스크립트가 없다.
기존 씬을 바탕으로 한 추가 수정이다. 이전 작업의 모든 그래픽을 수동으로 새로 제작한 것은 아니다.

저장 및 보존 검사
편집 중 Stage 02~05의 활성 상태를 Inspector에서 바꾸어 각 맵을 확인했다.
마지막에 Stage 02만 활성화하고 나머지는 비활성으로 복원한 뒤 저장했다.
새 오브젝트 ID 15개, Transform 15개, SpriteRenderer 15개가 추가됐다.
기존 씬 ID는 모두 유지했고, 물리 Transform 및 조상 78개의 위치·회전·크기가 동일하다.
플레이어·레버·학습 스크립트 및 참조에 예상하지 않은 변화는 없다.
Unity 저장 시 한국어 문자열의 유니코드 이스케이프와 일부 따옴표 표현이 정규화됐다.
출구의 기존 null 학습 참조가 명시적으로 직렬화됐고, 비상호작용 Slider의 TargetGraphic은
Unity OnValidate가 자기 오브젝트의 기존 Image를 연결했다. FillRect와 전압 발사기 참조는 동일하다.

검증 방식
원본 Unity 에디터에서 Play 렌더링을 확인했다.
네 스테이지의 기존 자동 완주/학습/클리어/최소 전압 검사와 캡처 도구는 별도 검증 복사본에서 실행한다.
검증 복사본에는 Ctrl+S로 저장한 원본 씬을 바이트 그대로 복사한다. 배치를 생성하거나 수정하지 않는다.
검증 코드와 기능 코드는 이번 수정에서 추가하거나 변경하지 않았다.
마우스·키보드로 직접 완주한 것으로 주장하지 않는다. 완주 결과는 기존 자동 검사 보고서가 기준이다.
프로젝트 루트 Logs/ElectricHierarchyEdit*Report.json과 ElectricHierarchyStage02~05.png를 참고한다.
