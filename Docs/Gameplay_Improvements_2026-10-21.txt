1. 적용 내용

1순위 — 안내와 시야
  학습 카드는 좌상단에서 기본 접힘으로 시작한다. 기존 버튼에 도움말 열기/닫기를 표시한다.
  상단은 지금 할 일 한 줄과 최소 측정값·별·전하를 보여 준다.
  3번은 B 기준 저장 → 레버로 거리 변경 → E 비교 발사를 단계별로 안내한다.
  q/Q 단축키와 자세한 설명은 기존 도움말 카드에서 확인한다.
  같은 조건 비교, 중성 공, 발사 범위 밖, 충전 부족 등의 거절 이유를 화면에 잠시 표시한다.
  자동 바운스와 Space의 0→+→−→0 순환, R 전체 재시작도 안내한다.

2순위 — 조작 규칙
  4번 Z/X/C는 Space와 같이 현재 위치·속도·별·학습 기록을 유지하며 전하를 바꾼다.
  전하 변경으로 출발점에 돌아가거나 별이 사라지는 동작을 제거했다.
  3번 움직이는 물체는 왕복 장애물로 명확히 안내한다. 기존 비자동바운스 물리 역할은 유지했다.

3순위 — 진행 중 전기 원리 활용
  4번 기존 전기장의 가로 범위와 연결된 기존 시각 요소만 확장했다.
  판 간격·전압·전기력·발판 경로는 그대로다.
  음전하로 장 안에서 실제 1단위 상승 → 상부 별 → 중성으로 실제 1단위 하강 → 음전하로 하강 제동을 연결했다.
  제동은 하강 중 위쪽 힘을 0.1초 이상 실제로 받아야 인정한다. 출구의 음전하·하향장 조건도 유지한다.
  체크포인트 복귀의 순간 이동은 이동 학습에 집계하지 않는다.
  2·3·5번의 기존 필수 학습과 기본 발판 경로는 유지했다.

4순위 — 제동과 재도전
  일반 이동 감속을 3→9로 높이고 반대 방향 입력에도 제동을 적용했다.
  최고속도·가속도·질량·중력·점프는 유지했다. 전기 발사 후 무입력 관성도 유지한다.
  최고속도 7에서 정지까지 약 2.34초/8.10단위 → 약 0.78초/2.65단위로 감소했다.
  반대 방향 입력 시 0 통과는 약 0.78초, -7 도달은 약 2.18초다.
  Backspace는 최근 실제 착지 발판으로 돌아가며 학습·별·전하·장치 기록을 보존한다.
  R은 전체 초기화다. 맵 아래로 크게 추락할 때도 발판 복귀를 사용한다.

5순위 — 선택 도전과 개인 기록
  공통: 발판 복귀 없이 완주.
  2번: 실제 인력과 척력 체험.
  3번: 준비 상태에서 변수 하나만 바꾼 적격 비교.
  4번: 전하 전환 4회 이내 완주.
  5번: 실제 50~55V 효율 발사 후 완주.
  선택 도전은 필수 출구 조건을 늘리지 않는다. 기록은 기존 도움말 Text에 표시한다.
  배지·최소 복귀 횟수·5번 최저 적격 전압은 재실행 후에도 유지된다.
  3번의 한 변수 도전은 실제 적격 비교 당시 기록을 사용한다. 공중 재발사가 배지를 잘못 주거나 지우지 않는다.
